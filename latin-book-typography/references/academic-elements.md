# Academic book elements

**Status: draft checklist.** House rules in SKILL.md and the user's or publisher's style guide take precedence. Use this to know what to inspect; do not impose these as fixed values.

- **Footnotes and endnotes:** consistent note style, size and leading distinct from body; reference marks set as superscript via a character style; notes that split across pages keep at least two lines on each side; note numbering restarts or continues as the project specifies.
- **Bibliography:** hanging indent through a paragraph style, not spaces or tabs; consistent punctuation and italics as written by the author (do not rewrite entries).
- **Block quotations:** their own paragraph style (indent, size or spacing as specified); no straight quotes; keep the block's first and last lines off isolated page positions as with body text.
- **Running heads:** content and position as specified, usually suppressed on chapter-opening and blank pages; check they match the section they sit in.
- **Index:** usually set smaller and in columns; prioritise avoiding widows, orphans and runts here as for other back matter; page references are checked at completion like the contents page.
- **Tables:** consistent table styles; no cell overset; tables that break across pages repeat header rows if the project wants it.
- **Non-breaking spaces:** keep units and short references together, for example "p. 12", "pp. 12–14", "et al.", "fig. 3", initials in names and numbers with units. Use no-break spaces or no-break formatting, never manual line breaks.
